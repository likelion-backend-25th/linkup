## 1. 기획 개요

### 1.1 프로젝트 배경 및 목적

기존 SNS의 콘텐츠 소비 및 사용자 간 소통 기능을 기반으로, 크리에이터가 콘텐츠를 제공할 수 있는 SNS 플랫폼을 기획한다.
사용자는 관심 있는 크리에이터를 팔로우 하고 콘텐츠에 좋아요 · 댓글 등으로 참여할 수 있으며, 구독을 통해 차별화된 콘텐츠와 혜택을 이용할 수 있도록 한다.
이를 통해 크리에이터와 사용자가 지속적으로 소통하고 관계를 형성할 수 있는 콘텐츠 기반 SNS 플랫폼을 구축하는 것을 목표로 한다.

### 1.2 서비스 주요 특징

- 일반 사용자가 게시글을 작성하고 팔로우, 좋아요, 댓글 등을 이용할 수 있는 기본 SNS 기능 제공
- 크리에이터가 게시글, 이미지, 파일 등의 콘텐츠를 공유하고 구독자 전용 콘텐츠를 제공할 수 있는 기능 지원
- 사용자가 관심 있는 크리에이터를 유료 구독하여 **구독자 전용 콘텐츠에 접근할 수 있는 서비스 제공**
- 댓글, 좋아요, 팔로우 등 사용자 활동에 대한 **알림 제공**
- 검색 및 개인화된 피드를 통해 **관심 있는 사용자와 콘텐츠를 탐색할 수 있는 환경 제공**

## 2. 주요 기능 요구사항

### 2.1 메인페이지 기능

- **최신 게시글 피드 조회** : 팔로우한 사용자가 작성한 최신 게시글을 피드 형태로 제공
- **구독 콘텐츠 조회** : 구독 중인 크리에이터의 일반 게시글 및 구독자 전용 게시글 조회
- **게시글 상호작용** : 게시글에 좋아요를 누르거나 댓글을 작성하여 다른 사용자와 소통
- **작성자 프로필 조회** : 게시글 작성자의 프로필을 선택하여 해당 사용자의 프로필 페이지로 이동
- **게시글 정보 제공** : 게시글의 이미지, 내용, 작성 시간, 좋아요 수 및 댓글 수 등의 정보 표시
- **게시글 추가 조회** : 무한 스크롤을 통해 게시글을 연속적으로 조회
- **주요 메뉴 이동** : 검색, 알림, 프로필 등 서비스의 주요 기능으로 이동

### 2.2 회원 관리 기능

- **회원가입 및 로그인** : OAuth2를 이용한 회원가입 및 로그인 (구글/ 카카오 계정)
- **회원 프로필 관리** : 닉네임, 프로필 이미지, 자기소개 등 개인 정보 수정
- **회원 정보 조회** : 자신의 계정 정보 확인
- **팔로우 관리** : 팔로우한 크리에이터 및 나를 팔로우하는 사용자, 내가 팔로잉하는 사용자 관리
- **구독 관리** : 구독 중인 크리에이터와 구독 상태 확인
- **계정 관리** : 로그아웃 및 회원 탈퇴 기능 제공
- **차단 관리**: 차단 사용자 관리

### 2.3 게시글 기능

- **게시글 작성** : 텍스트와 이미지 등을 활용하여 새로운 게시글 작성
- **게시글 조회** : 작성된 게시글의 내용, 이미지, 작성자, 작성 시간 등의 상세 정보 조회
- **게시글 수정 및 삭제** : 자신이 작성한 게시글의 내용과 이미지를 수정하거나 게시글 삭제
- **게시글 공개 범위 설정** : 전체 공개 또는 구독자 전용 등 게시글의 공개 범위 설정
- **좋아요 관리** : 게시글에 좋아요를 등록하거나 취소하고 좋아요 수 확인
- **댓글 관리** : 게시글에 댓글을 작성하고 작성한 댓글을 수정하거나 삭제
- **게시글 목록 조회** : 특정 사용자가 작성한 게시글을 목록 형태로 조회
- **게시글 신고** : 부적절한 게시글을 신고하여 관리자에게 전달

### 2.4 구독 기능

- **크리에이터 구독** : 원하는 크리에이터를 선택하여 결제를 통해 구독 시작
- **구독 결제** : 토스페이먼츠를 이용하여 크리에이터의 유료 구독 결제
- **구독 상태 관리** : 구독 시작일, 만료일 및 현재 구독 상태 확인
- **구독자 전용 콘텐츠 이용** : 구독 중인 크리에이터가 제공하는 구독자 전용 게시글 및 콘텐츠 조회
- **구독 목록 조회** : 현재 구독 중인 크리에이터와 구독 정보를 목록 형태로 조회
- **구독 해지** : 이용 중인 크리에이터 구독을 해지하고 구독 만료 여부 확인 ( 1일 이내 환불 시 전체 환불? )
- **구독 결제 내역 조회** : 크리에이터별 구독 결제 금액, 결제일 등 과거 결제 내역 확인

### 2.5 크리에이터 기능

- **구독 상품 관리** : 크리에이터별 구독 상품을 제공하며 월 4,900원의 고정된 가격으로 운영
- **크리에이터 신청 및 승인** : 일반 회원이 조건 (팔로워 수 등) 만족 시 크리에이터 신청이 가능하고 신청하면 자동으로 자격 획득
- **구독자 전용 게시글 작성** : 유료 구독 회원만 조회할 수 있도록 공개 범위를 설정하여 전용 콘텐츠 제공
- **구독자 전용 파일 업로드** : 구독자 전용 게시글에 파일 업로드 기능 제공하며 파일은 최대 100MB까지 등록 가능
- **구독자 전용 관리** : 크리에이터가 자신의 구독자 목록 및 구독 상태를 조회
- **구독 현황 조회** : 구독자 수 및 총 구독 비용 등을 확인하여 단순한 통계 제공

### 2.6 알림 기능

- **알림 제공** : 댓글, 좋아요, 팔로우, 구독 등 주요 활동 발생 시 해당 사용자에게 알림 제공
- **알림 목록 조회** : 사용자에게 발생한 알림을 최신순으로 목록 형태로 조회
- **알림 상세 이동** : 알림 선택 시 관련 게시글, 댓글 또는 사용자 프로필 등의 페이지로 이동
- **알림 읽음 처리** : 사용자가 확인한 알림을 읽음 상태로 변경하고 읽지 않은 알림과 구분
- **읽지 않은 알림 표시** : 확인하지 않은 알림의 존재 여부 및 개수를 표시
- **알림 삭제** : 사용자가 불필요한 알림을 개별 또는 전체 삭제

### 2.7 관리자 기능

- **회원 관리** : 전체 회원 목록과 회원 정보를 조회하고 회원 상태 및 이용 권한 관리
- **신고 관리** : 사용자, 게시글 및 댓글에 접수된 신고 내역을 조회하고 처리 상태 관리 / 신고가 처리되면 해당 사용자의 경고가 카운트 → 1회 경고, 2회 게시글 작성 제한, 3회 회원 정지
- **구독/결제 관리** : 사용자의 구독 현황과 결제 내역 조회

### 3.2 팀 컨벤션

- 🌿 **브랜치 전략**: 모든 작업은 브랜치 기반으로 진행하며, `main, dev` 브랜치에 직접 `push`하지 않는다.
- 🔄 **동기화**: 작업 시작 전 최신 `dev` 브랜치를 `pull` 받는다.
- 🔀 **코드 리뷰**: 기능 단위로 작업을 나누고 PR(Pull Request)을 통해 코드 리뷰 후 병합한다.
- 💬 **의사 결정**: 기술적 의견이 다를 경우 근거 기반으로 논의 후 다수결로 결정한다.
- 📝 **코드 규칙**: 변수명은 미리 정한 Naming Convention을 통일하여 사용하고, 주요 로직에 주석을 작성한다.
- 📌 **Git 커밋 규칙**: 팀 내 정해진 Commit Convention을 준수한다.
- ⏰ **근태 공유**: 결석이나 지각 발생 시 최소 전날 미리 팀원들에게 공유한다.
